# Phuket Last Day Luxury Planner 🏝️✨

**Phuket Last Day** is a premium web service designed to optimize the final day of a trip to Phuket. It features an AI-powered itinerary generator that creates the most efficient travel route based on flight schedules and user preferences, ensuring a seamless and luxurious experience.

## ✨ Key Features

- **AI Route Optimization (Far-to-Near Algorithm)**: Automatically arranges destinations starting from the farthest point to minimize travel time.
- **Smart Time Management**: Calculates travel times with real-time traffic considerations (1.5x during rush hours) and category-based stay durations.
- **Airport Deadline Alert**: Prevents scheduling conflicts by enforcing a strict airport arrival deadline based on flight times.
- **Luxury UI/UX**: A dark-themed, gold-highlighted interface optimized for mobile devices, providing a premium user experience.
- **Similan Luggage Logic**: Specialized logic for handling luggage fees and constraints for Similan Islands tours.
- **Direct Communication**: One-click connection to Line messengers for real-time support and driver communication.

## 🚀 Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Vanilla CSS (Styled Components approach), Lucide React Icons
- **Backend (Optional)**: Python (FastAPI) for advanced logic processing (Simulated in frontend for demo)
- **Deployment**: Vercel

## 🛠️ Installation & Run

1.  **Clone the repository**
    ```bash
    git clone https://github.com/YOUR_USERNAME/phuket-luxury-platform.git
    cd phuket-luxury-platform
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    ```

## 📦 Deployment (Vercel)

This project is optimized for Vercel deployment.

1.  Push your code to GitHub.
2.  Import the repository in Vercel Dashboard.
3.  The build settings are automatically detected (Vite).
4.  Deploy!
